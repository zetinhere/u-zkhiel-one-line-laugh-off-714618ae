One line, 94 characters: a silent retreat where even the silence turns on you.

> I went to a silent retreat. Twenty minutes in, the silence filed a noise complaint against me.

`main.py` scores twelve candidate one-liners against the judge's published brief
(laugh first, then surprise, economy, and freshness) and writes the winner to
`/output/entry.txt`. Deterministic: no network, no input, no randomness.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (no trailing newline, so the file
is exactly the one line the gate measures).
